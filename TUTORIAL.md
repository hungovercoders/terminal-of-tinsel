# Building Terminal of Tinsel

There is a course for that: **Auntie Aerial's Night School**, 24 nights that build Terminal of Tinsel from an empty folder to a released Rust CLI, one lesson for each door of the advent calendar.

📺 *"Twenty-four nights. Bring a mince pie."*

**Start here: [course/README.md](course/README.md)**

- Nights 1 to 10 are build-along: type the code, run it, see it work.
- Nights 11 to 24 teach the ideas behind the finished program and point at the files in this repository.
- Every night ends with an exercise and a Rust fact.

The finished code is in this repository; the course explains how it got that way.
