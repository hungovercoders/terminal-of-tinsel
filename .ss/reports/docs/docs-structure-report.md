## How to Fix

1. **Unrouted doc:** add a row to the README above it, or to the map, in the form `Before you <do X>, read <doc> for <what it holds>`. The trigger first, then "read", then the file as a markdown link.
2. **Soft route:** the map links a doc without saying when to read it. Reword the row.
3. **Route too deep:** route the doc from the map or `AGENTS.md` directly; a README that only routes onward is a turn spent on nothing.
4. **Doc over the line budget:** split it by concern and route each part.
5. **Legacy index:** fold `docs/index.md` into the map README and delete it.
